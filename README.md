# Portafolio Web Personal - Valentino Cortese

Sitio web personal desarrollado con **HTML5, CSS3 y JavaScript vanilla (ES6+)**, sin frameworks ni dependencias de servidor. 

## Estructura del proyecto

```text
.
├── index.html
├── proyectos.html
├── README.md
├── assets/
│   ├── foto.jpg
│   ├── sc1.png
│   ├── sc2.jpg
│   ├── sc3.jpg
│   ├── sc4.jpg
│   ├── sc5.jpg
│   └── ValentinoCorteseCV.pdf
├── css/
│   └── styles.css
└── js/
    ├── app.js
    ├── language.js
    ├── theme.js
    └── translations.js
```

## Características

- Diseño minimalista y responsive, optimizado para desktop y mobile
- Tema claro/oscuro con preferencia de usuario y persistencia en `localStorage`
- Selector de idioma español / inglés
- Navegación accesible con menú hamburguesa en dispositivos móviles
- Scroll suave a secciones internas y actualización de item activo en el navbar
- Micro-interacciones con reveal al entrar en viewport
- Slider simple para visualizar capturas o proyectos
- Copiar correo al portapapeles desde el botón de contacto

## Despliegue

- Como sitio estático, no requiere compilación ni dependencias.
