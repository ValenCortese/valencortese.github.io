# Portafolio Web Personal - Valentino Cortese

Sitio web personal desarrollado con **HTML5, CSS3 y JavaScript vanilla (ES6+)**, sin frameworks ni dependencias de servidor.

## Estructura del proyecto

```text
portafolio/
├── index.html
├── proyectos.html
├── README.md
├── assets/
│   └── foto.jpg
│   └── sc1.png
│   └── sc2.jpg
│   └── sc3.jpg
│   └── sc4.jpg
│   └── sc5.jpg
│   └── ValentinoCorteseCV.pdf
├── css/
│   └── styles.css
└── js/
    └── script.js
```

## Características

- Diseño minimalista, dark mode y responsive (mobile-first)
- Navegación con menú hamburguesa en mobile
- Scroll suave entre secciones
- Micro-interacciones sutiles al hacer scroll
- HTML semántico y accesible
- Rutas relativas compatibles con GitHub Pages

## Personalización rápida

- Colores: editar variables CSS en `:root` dentro de `css/styles.css`
- Contenido: editar secciones en `index.html`
- Interacciones: ajustar lógica en `js/script.js`
